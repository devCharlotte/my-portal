# Security Notes

정적 웹 애플리케이션 코드 안에 고정 비밀번호나 API 비밀키를 넣으면 누구나 소스에서 확인할 수 있습니다. 이 프로젝트는 해당 값을 하드코딩하지 않습니다.

암호화된 `.runvault` 파일 또는 사용 중인 브라우저 프로필을 공격자가 확보하면 오프라인 비밀번호 추측 공격은 원리적으로 가능합니다. 충분히 길고 재사용하지 않는 비밀번호를 사용하십시오.

금고가 열린 동안에는 브라우저 메모리에 복호화된 데이터가 존재합니다. 신뢰할 수 없는 브라우저 확장 프로그램이나 변조된 배포 페이지에서는 사용하지 마십시오.
